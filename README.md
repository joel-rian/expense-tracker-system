# 💰 Personal Finance Dashboard

A **responsive web application** built to help users track their expenses, income, and financial goals.  
This project demonstrates a modern front-end structure, clean UI components, and real-world business logic for financial management.

---

## 🚀 Tech Stack

| Area | Technologies |
|------|---------------|
| **Frontend** | React, Tailwind CSS |
| **State Management** | Context API / React Hooks |
| **Backend** | Node.js + Express |
| **Database** | PostgreSQL / Prisma ORM |
| **Deployment** | Vercel |
| **Version Control** | Git + GitHub |

---

## 🧩 Features

✅ Add, edit, and delete transactions (CRUD)  
✅ View expense/income balance in real time  
✅ Filter transactions by category and date  
✅ Responsive UI design  
✅ Ready for API integration (backend or cloud)  

---

## ⚙️ Installation

```bash
# Clone the repository
git clone https://github.com/joel-rian/expense-tracker-system.git

# Enter the project folder
cd expense-tracker-system

# Install dependencies
npm install

# Run the app
npm run dev
